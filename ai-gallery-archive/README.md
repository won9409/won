# 특갤 AI 데일리 아카이브 MVP

훈련소 기간 동안 `특이점이 온다` 갤러리에서 하루에 어떤 AI 떡밥이 오갔는지를 날짜별로 저장하기 위한 최소 구조입니다.

## 지금 단계의 목표

- 매일 자료를 **날짜별 JSON + 읽기 쉬운 Markdown** 두 형태로 보존
- 나중에 21일치를 한꺼번에 읽어도 흐름을 복원할 수 있도록 원문 링크와 반응 수치를 같이 보존
- 카드뉴스/웹 대시보드는 퇴소 후 이 데이터를 이용해 추가

## 폴더 구조

```text
ai-gallery-archive/
├─ data/                 # 나중에 웹 대시보드가 읽을 구조화 데이터
├─ archive/              # 사람이 바로 읽는 날짜별 브리핑
├─ prompts/              # 데일리 수집·정리 기준
└─ README.md
```

## 하루에 남길 내용

1. 오늘의 한줄 요약
2. 핵심 떡밥 3~6개
3. 시간순 타임라인
4. 특갤 반응/논쟁 방향
5. 개념글·정보글 여부와 조회/추천 수치
6. 원문 링크
7. `확인된 사실 / 갤러리 주장·추측` 구분
8. 다음날 이어서 볼 떡밥

## 샘플 데이터에 대한 주의

현재 웹 도구에서 디시인사이드 실시간 8월 19일 목록을 안정적으로 불러오지 못해, 테스트 결과물은 **웹에서 정상 확인 가능한 2026-08-10 목록 일부**를 사용했습니다. 따라서 `archive/2026-08-10.md`는 전체 하루를 완전 수집한 보고서가 아니라 **결과물 형식을 확인하기 위한 MVP 샘플**입니다.

## 최종적으로 원하는 흐름

```text
특갤 수집 → 날짜별 데이터 저장 → 21일 누적
                              ↓
                    퇴소 후 전체 재편집
                              ↓
                  카드뉴스 + 웹 대시보드
```
